Reel Shuffle Viewer

Load a JSON file containing your reel links to start. Each entry can either be a string URL or an object like:

[
  {
    "url": "https://www.instagram.com/reel/ABC12345/",
    "description": "Optional caption shown under the embed"
  }
]

Reels are displayed in a random order every time you load or shuffle the list.

Embeds come directly from Instagram. Viewers may need to be logged in to Instagram in their browser to watch the reels.
